Journey: **signup** (run folder `runs/<date>-signup/`).

Goal: experience LetsEarn as a brand-new user and find where they would drop off before their first tracked click-out.

1. Ask the user whether to clear app data first (fresh install state). Do not clear it yourself.
2. Launch LetsEarn. Record every screen from splash to home: intro slides, permission prompts, signup/login options, OTP, referral-code field, profile questions.
3. Pause for the user to complete OTP/login.
4. On home, note: is it obvious what the app does and how cashback works within 5 seconds? Is there a clear first action?
5. Follow the most prominent path to a store and tap the "shop/activate cashback" button once. Stop as soon as the merchant starts loading, then go back.
6. Count taps and screens from launch to click-out.

Report focus: steps to first click-out, unclear value prop, permission/OTP friction, trust signals (cashback amount shown, tracking explained, payout proof).
