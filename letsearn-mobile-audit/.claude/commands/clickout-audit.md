Journey: **clickout** (run folder `runs/<date>-clickout/`). Store to test: $ARGUMENTS (default: pick a top store like Flipkart, Amazon or Myntra).

1. From home, find the store three ways if available: search, category browse, and home banners/deals. Note which is fastest.
2. On the store page, record: cashback rate and how clearly it is shown, terms/exclusions, "tracking time" and "confirmation time" info, coupons/deals.
3. Tap the main "shop now / activate" button ONCE. Note any interstitial (loading screen, "cashback activated" message, app-vs-browser choice). Go back as soon as the merchant starts loading.
4. Check what the user sees on return: any confirmation that the click was tracked, or a prompt to come back?

Report focus: discoverability, clarity of the cashback offer, trust before leaving the app, and whether the user knows what to do next.
